# Chess.com Game Review System

A full chess.com game review system with:
- Web UI
- HTTP API
- PGN parser and move-by-move annotations
- Chess.com integration (latest game by username or game URL)

## Run

```bash
python app/main.py
```

Then open `http://localhost:8000`.

## API

### POST `/api/review`

Body can contain one of:

```json
{"pgn":"..."}
```

```json
{"game_url":"https://www.chess.com/game/live/..."}
```

```json
{"username":"someuser"}
```

## Notes

- This project is fully self-contained and uses only Python's standard library for runtime.
- Move classifications are generated by a lightweight heuristic model to provide practical review output quickly.
